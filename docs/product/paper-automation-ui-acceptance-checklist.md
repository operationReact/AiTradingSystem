# PAPER automation UI acceptance checklist

- [ ] Home shows PAPER + Manual/Automated without dominating the portfolio hierarchy.
- [ ] Home shows Risk protected or Trading paused in customer language.
- [ ] AI/Research clearly distinguishes Manual View & Trade from Automated watching/evaluation.
- [ ] Trade screen always shows stop loss, target, risk summary and PAPER action.
- [ ] Portfolio shows open position + unrealized P&L and closed/history + realized P&L.
- [ ] More exposes Trading mode and Execution preferences at account level.
- [ ] LIVE is visibly unavailable/Coming later and cannot be activated.
- [ ] Angel One is presented as connected/read-only account data, not LIVE order permission.
- [ ] No raw enums/status codes/provider errors/operator controls in normal flows.
- [ ] Neon Futuristic AI is default; Clean Modern remains secondary.
- [ ] Phone-size screenshots are compared with canonical Figma.
- [ ] Loading/empty/error/paused states are visually handled.
- [ ] Controls reread backend state after mutation/reconnect.

This checklist is product acceptance, not a substitute for widget tests or CI.
