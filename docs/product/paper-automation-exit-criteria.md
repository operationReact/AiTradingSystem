# PAPER automation phase exit criteria

Phase exit requires evidence, not intent:

- persisted account-scoped mode state integrated;
- existing authoritative risk/emergency policy used by both Manual and Automated PAPER;
- persisted automated order/fill/position/capital/P&L/history journey proven end to end;
- retry/restart idempotency proven;
- Secure Sign In/account session used by the client;
- actual Flutter customer controls/lifecycle implemented;
- Angel One read-only boundary preserved;
- exact-head backend/Flutter/security/visual/APK gates green;
- canonical Figma phone evidence accepted;
- backend-connected Android physical-device acceptance for touched flows;
- LIVE/broker submission disabled.

Only after these criteria are complete should the phase be marked complete in both authoritative Notion pages.
