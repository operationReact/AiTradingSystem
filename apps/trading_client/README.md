# AiTradingSystem Flutter client

FC-02/FC-03 foundation for Flutter web, Android and iOS.

## Architecture

- `lib/src/domain`: typed server evidence; unknown enum values fail closed to `HealthState.unknown`.
- `lib/src/data`: read-only HTTP repository and memory-only development operator session.
- `lib/src/presentation`: controller above presentation and the operations-health surface.
- `lib/src/theme`: `neonFuturisticAi` and `cleanModern` using semantic `ThemeExtension` values plus light/dark/system.

The first slice only calls `GET /api/operations/health`. It never queues/replays a mutation and does not authorize trading.

## Local bootstrap

Use Flutter 3.47.x stable. From this directory run:

```bash
flutter create --platforms=web,android,ios --project-name trading_client .
flutter pub get
flutter analyze
flutter test
flutter run --dart-define=API_BASE_URL=http://localhost:8080
```

Platform wrappers are regenerated by CI from the pinned stable line before build validation so generated Gradle/Xcode metadata matches the SDK. Product Dart sources, route/auth/theme behavior and tests remain repository-owned.
